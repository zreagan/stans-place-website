# Stan's Place

A private collection website for **Stan Hollingsworth** — featuring 1930s Packard motor cars, classic automobiles, and vintage tractors.

## Contents

- `index.html` — single-page site
- `css/styles.css` — showroom-inspired styling
- `js/main.js` — nav, filters, gallery lightbox, thumbnail swaps
- `images/` — web-optimized photos from the collection
